# 🧠 ДЗ: Кластеризация на эмбеддингах нейросети

**Цель:**
попробовать кластеризацию не по «сырым» данным, а по признакам, полученным из нейросети (например, ResNet-18), и сравнить разные алгоритмы кластеризации на этих эмбеддингах.

---

Можно взять реализацию из [практической работы по классификации (ResNet-18)](https://github.com/AlexandrAxyonov/Intro_in_ML/blob/main/practices/practice_Classification/classification.ipynb)
либо попробовать другую модель, которая позволяет извлекать вектор признаков из изображений.

---

## Что нужно сделать

1. Работать с датасетом **MNIST** из практики по кластеризации. Предобработку можно взять из практики, либо усилить её.
2. Выбрать **минимум 2 алгоритма кластеризации** из практики, либо взять другие алгоритмы.
   Например:
   - другие варианты иерархических методов;
   - подходящие модификации K-Means;
   - поиграть с параметрами (например, `linkage` для иерархической кластеризации), которые меняют поведение алгоритма.
3. Оценить алгоритмы по базовым метрикам:
   - одна внутренняя (например, **silhouette**),
   - одна внешняя (**ARI**).
4. Визуализация приветствуется: использовать **PCA** или **t-SNE**, так как 784 признака, и без понижения размерности визуализировать сложно.
5. При необходимости к каждому блоку кода с выводами давать короткие пояснения по этим выводам.

---

## Оценка

- За нейросетевые эмбеддинги и остальной пайплайн как в практике — **5 баллов**.
- Любое ваше нововведение приносит дополнительные баллы: дополнительная метрика, новый алгоритм, понятная визуализация, нейросеть для эмбеддингов, отличная от той, что я предложил — **+1 балл**.
- Плюс/минус балл за аккуратность кода и внятность выводов.
- **Максимум: 8 баллов.**
